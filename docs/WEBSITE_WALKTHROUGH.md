## Executive Overview

### Mission Statement
"Helping families stay safe online, from kids on social media to seniors targeted by scammers."

### What GetCyberRight.com Offers
GetCyberRight is a US-based family cyber protection platform helping families stay safe online across six continents. Built from personal experience with cyber fraud, we provide free resources for everyone from kids on social media to seniors targeted by scammers.

The platform serves three core audiences:

1. **Youth Protection** - Safety from social media dangers, gaming threats, and mobile risks
2. **Senior Safety** - Protection from mobile money fraud (M-Pesa, MTN, Airtel), SIM swap attacks, and WhatsApp scams
3. **Real-time News** - Cyber/IT/AI news and updates from 20+ trusted sources

### Unique Positioning
The only platform combining Youth Protection + Senior Safety + Real-time News with mobile-first design serving families globally across six continents.

**Contact**: hello@getcyberright.com

### Target Audiences
| Audience | Primary Concerns | Key Pages |
|----------|------------------|-----------|
| **Youth (Teens)** | Social media safety, gaming, online predators | Youth Safety |
| **Parents** | Protecting children, monitoring, education | Parent Guide |
| **Seniors** | Mobile money fraud, phone scams, WhatsApp tricks | Senior Safety |
| **General** | Staying informed, cyber hygiene basics | News, Cyber Awareness |

## Global Navigation Elements

### Header Navigation
The header appears on every page and includes:
- **Logo** - Clicking returns to homepage
- **Main Menu** - Links to primary sections
- **Theme Toggle** - Switch between light/dark mode

### Footer
Present on every page with:
- Quick links to all major sections
- Newsletter subscription form
- Social media links
- Legal links (Privacy Policy, Terms of Service)
- Copyright information

### Floating Help Button (Always Visible)
A red floating button in the bottom-right corner of every page with two options:
1. **"I've been scammed"** → Links to Emergency Help page
2. **"Check if it's a scam"** → Links to Scam Checker tool

This ensures victims can always find help without searching.

## Interactive Features

### 1. Scam Checker Tool (/scam-checker)
**Purpose:** AI-powered tool to help users verify if a message, call, or situation is a scam.

**How to use:**
1. Navigate to /scam-checker
2. Describe the suspicious situation
3. Submit for analysis
4. Receive verdict: Safe, Suspicious, or Scam
5. Get recommended actions

### 2. Quick Assessment (/quick-assessment)
**Purpose:** Interactive quiz to assess personal cybersecurity practices.

**Features:**
- Multiple-choice questions
- Instant feedback
- Points and achievement system
- Personalized recommendations
- Progress tracking

### 3. Cyber Hygiene Self-Check (/cyber-hygiene)
**Purpose:** Checklist-based tool to evaluate security habits.

**Categories assessed:**
- Password practices
- Device security
- Online behavior
- Privacy settings
- Backup habits

### 4. Newsletter Subscription
**Location:** Homepage footer and various page sections

**What subscribers receive:**
- Safety tips every Monday and Friday
- Audience-targeted content (youth, senior, or general)
- Breaking threat alerts

### 5. Floating Help Button
**Location:** Bottom-right corner of every page

**Features:**
- Always visible for easy access
- Red color for visibility
- Two quick options:
  - "I've been scammed" → Emergency Help
  - "Check if it's a scam" → Scam Checker
