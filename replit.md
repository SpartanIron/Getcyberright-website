# GetCyberRight - Cybersecurity Education Platform

## Overview
GetCyberRight is a family-focused cybersecurity education platform designed to provide practical knowledge to non-technical users such as families, parents, kids, seniors, and everyday individuals. Its core purpose is to demystify complex cybersecurity information through interactive safety assessments, real-time threat intelligence, and educational content tailored to specific audiences. The project aims to serve those overlooked by traditional corporate cybersecurity solutions, offering essential tools free of charge to start. The business vision is to become a leading resource for accessible cybersecurity education for all.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Brand Identity & Design
The platform uses a KnowBe4-inspired premium design language with dark teal (`#0A2A3C`), deep teal (`#00293C`), and orange accent colors aligned to the brand mascot (teal lock + orange accents). **Brand Colors**: Navigation, hero sections, page banners, newsletter, and CTA sections all use brand dark teal `#0A2A3C` for consistency. The footer uses `#081C26` (darkest teal-black). Dark sections alternate with light sections for visual rhythm. **Typography**: Sora (Google Font) is the sole typeface, weight 600 for headings, 400 for body. All headings use `letter-spacing: -0.025em`. Base body 18px (1.125rem) with line-height 1.4. **Buttons**: Pill shape (`rounded-full`) default via CVA base class. CTA arrow icons slide 5px right on hover via `.cta-arrow-right`. Icon buttons override to `rounded-md`. **Page Banners**: Clean split-layout with image on one side, text on navy background. No decorative circles. All inner pages use the same `PageBanner` component. **Homepage**: Emotional hero ("Your Family Is the Target. We Are the Shield."), FBI data stat bar, dark teal pillar tiles section, card-based content preview, image-backed audience paths, and image CTA footer. Audience-specific hubs (Kids, Seniors, Parents, Educators, Small Business) feature distinct themes. All card elements use image backgrounds with gradient overlays. All animations respect reduced motion. All human images depict diverse, multiracial individuals. Em dashes prohibited.

### Technical Implementation
The frontend is built with React 19, TypeScript, and Vite, using Wouter for routing, TanStack Query for state management, and Tailwind CSS with shadcn/ui for styling. Framer Motion handles animations, and React Hook Form with Zod manages forms. The design is mobile-first with dynamic SEO. The backend uses Express 5 on Node.js with TypeScript (ES modules) and REST endpoints, employing shared Zod schemas for input validation. Authentication is a custom system supporting email/password, TOTP MFA, Passkeys (WebAuthn), and session management. The data layer uses Drizzle ORM for PostgreSQL (serverless via Neon) with `drizzle-zod` for schema generation. Security measures include Helmet.js, multi-tier rate limiting, CSRF protection, payload limits, XSS/SQLi detection, secure cookie settings, input sanitization, Google reCAPTCHA, and API anomaly detection. Compliance is mapped to OWASP ASVS, CIS Controls, ISO 27001, NIST 800-53, and MITRE ATT&CK.

### Key Features
- **AI-Powered Tools**: AI Scam Analyzer, Scam Checker (for URLs, QR codes, etc.) with multi-source threat intelligence (VirusTotal, PhishTank, URLhaus, Google Safe Browsing, domain age/WHOIS, SSL, AlienVault OTX), Dezi AI Assistant (persistent floating widget connected to real Anthropic Claude AI via SSE streaming at `/api/conversations` and `/api/conversations/:id/messages`, with conversation persistence in `conversations`/`messages` DB tables and sessionStorage, contextual page-aware prompts, local password generation fallback, and graceful error handling), and Voice Clone Detector (educational demo). The URL reputation check runs all sources in parallel via `Promise.allSettled`.
- **Content & Education**: Training Academy with audience-specific learning paths, a comprehensive AI Prompt Library, Cyber Safety Guides System, Scam Intelligence Center (region-aware scam database), Cyber Threat Radar (front-facing real-time threat dashboard at /cyber-threat-radar), Cyber Awareness Hub (visual safety guides, checklists, and lead magnet at /awareness-hub), and Programmatic Scam Pages (SEO-optimized guides).
- **Security & Privacy**: Data Broker Removal System (automated personal data removal), Breach Monitoring, Password Generator, and Family Safety Codeword Generator.
- **Automation & Governance**: Automated Weekly Newsletter System, AI Content Guardrails, Automated Threat Intelligence (from 8 sources), Automated Content Governance System, Content Automation Engine (AI-powered article generation), Social Distribution Engine (auto-triggered on publish with idempotency guards for LinkedIn, X, Instagram, and short alerts), Email Alert System (sends subscriber notifications for high/critical threat alerts on publish), Growth Orchestrator with auto-publish scheduling (3-5 articles/week, admin toggle at /api/admin/growth/auto-publish, setting persisted to file). Content Automation Monitoring dashboard (success/failure rates, task breakdown by type, recent activity log). Initial content seeded on startup: 6 guides, 5 scam intel entries, 5 threat alerts. Social posts auto-seeded for all published content missing posts (with branded images). Badge definitions (12) auto-seeded on startup.
- **User Engagement**: Gamification & Achievement System (12 badge definitions seeded: scanner, education, streak, community categories with bronze/silver/gold/platinum tiers), Dynamic Trending Threats (geo-tagged, AI-powered alerts), Regional Scam Profiles (visual, region-specific scam information), User Feedback System, and The GetCyberRight Experience (teaser/waitlist page at /experience with family and vendor signup, `experience_waitlist` DB table, strict rate limiting, Zod validation with email format and type enum enforcement).
- **Admin & SEO**: Comprehensive Admin System for platform management, SEO Keyword Database (551+ keywords across 10 clusters), Internal Linking Engine, Dynamic Sitemap generation (server-rendered at /sitemap.xml with 127+ URLs including all published guides, alerts, scam intel, programmatic scam pages, and topic hubs), SSR middleware for search engine bots (`server/seo-renderer.ts`) serving full HTML with meta tags, structured data, and content for ALL pages (40+ static pages with unique titles/descriptions/canonicals + all dynamic content pages), and JSON-LD structured data (Organization, Article, BlogPosting, FAQPage, HowTo, WebApplication, Course, BreadcrumbList, Dataset). 52+ programmatic scam pages at /scams/:slug. 10 SEO topic cluster hub pages at /topics/:cluster (identity-theft, online-scams, phishing-attacks, etc.). Cross-linking between /scams/ pages and /scam-intel/ entries. Shared route registry (`server/known-routes.ts`) ensures proper 404 status codes for unknown URLs in both dev and production. Trailing-slash URLs 301-redirect to canonical (no-slash) versions.

- **AI Services**: Anthropic API (Claude), OpenAI.
- **Email Services**: Brevo, MailerSend, SMTP2GO, Resend.
- **Image Processing**: Tesseract.js (OCR), jsQR (QR code decoding), Sharp (social media image generation/compositing).
- **Social Publishing**: Social Distribution Engine with infographic-style branded image generation (`server/socialImageService.ts`). Images use SVG templates rendered to WebP via Sharp with the brand padlock logo (`lock-logo-transparent.png`) composited on top. Infographic layout includes: topic-specific real stat callouts (e.g. "$10.3B lost to scams"), 3 actionable tips as bullet points, SVG topic icons, "8 Threat Intelligence Feeds" badge, brand colors (#0A2A3C dark teal + topic accent colors), and GetCyberRight.com branding. Landscape layout for FB 1200x630, LinkedIn 1200x627, X 1200x675; square layout for Instagram 1080x1080. Images stored in `.local/social-images/` and served at `/api/social-images/:filename` (with `dotfiles: "allow"` for Express sendFile). Hash includes "v2" suffix for cache-busting from old images. **Buffer is the primary publishing channel** (`server/bufferPublisher.ts`) using Buffer's GraphQL API at `api.buffer.com/graphql` (org ID: `69b48dd8282d615a79db2ab3`). Connected Buffer channels: Facebook ("Getcyberright") and LinkedIn ("getcyberright"). Posts are queued via `createPost` mutation with `addToQueue` mode and `automatic` scheduling. Direct platform API publishers (LinkedIn, Facebook, Instagram, X) serve as fallback when Buffer is unavailable. Admin endpoints: `/api/admin/social/buffer-status` (Buffer connection status), `/api/admin/social/connected-platforms` (all platforms including Buffer). Env vars: BUFFER_API_KEY (primary), LINKEDIN_ACCESS_TOKEN, FACEBOOK_PAGE_TOKEN, FACEBOOK_PAGE_ID, INSTAGRAM_ACCESS_TOKEN, INSTAGRAM_USER_ID, PUBLIC_IMAGE_BASE_URL, X_API_KEY, X_API_SECRET, X_ACCESS_TOKEN, X_ACCESS_SECRET.
