# GetCyberRight - Cybersecurity Education Platform

## Overview
GetCyberRight is a family-focused cybersecurity education platform designed to provide practical knowledge to non-technical users such as families, parents, kids, seniors, and everyday individuals. Its core purpose is to demystify complex cybersecurity information through interactive safety assessments, real-time threat intelligence, and educational content tailored to specific audiences. The project aims to serve those overlooked by traditional corporate cybersecurity solutions, offering essential tools free of charge to start. The business vision is to become a leading resource for accessible cybersecurity education for all.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Brand Identity & Design
The platform uses a KnowBe4-inspired premium design language with dark teal (`#0A2A3C`), deep teal (`#00293C`), and orange accent colors. Typography uses Sora (Google Font), 600 weight for headings, 400 for body. Buttons are pill-shaped, with CTA arrow icons sliding right on hover. Page banners feature a clean split-layout with image and text on a navy background. The homepage includes an emotional hero section, FBI data stat bar, dark teal pillar tiles, card-based content previews, image-backed audience paths, and an image CTA footer. Audience-specific hubs for Kids, Seniors, Parents, Educators, and Small Businesses have distinct themes. All animations respect reduced motion, and all human images depict diverse individuals.

### Technical Implementation
The frontend is built with React 19, TypeScript, and Vite, utilizing Wouter for routing, TanStack Query for state management, and Tailwind CSS with shadcn/ui for styling. Framer Motion handles animations, and React Hook Form with Zod manages forms. The design is mobile-first with dynamic SEO. The backend uses Express 5 on Node.js with TypeScript and REST endpoints, employing shared Zod schemas for input validation. Authentication is a custom system supporting email/password, TOTP MFA, Passkeys (WebAuthn), and session management. The data layer uses Drizzle ORM for PostgreSQL (serverless via Neon) with `drizzle-zod` for schema generation. Security measures include Helmet.js, multi-tier rate limiting, CSRF protection, payload limits, XSS/SQLi detection, secure cookie settings, input sanitization, Google reCAPTCHA, and API anomaly detection. A GDPR-compliant cookie consent banner (`client/src/components/cookie-consent.tsx`) with granular controls and localStorage persistence is included.
