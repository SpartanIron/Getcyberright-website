# GetCyberRight - Cybersecurity Education Platform

## Overview
GetCyberRight is a family-focused cybersecurity education platform designed to simplify cybersecurity for non-technical users such as families, parents, children, and seniors. It aims to be a leading, accessible resource by offering interactive safety assessments, real-time threat intelligence, AI-powered scam detection, data broker removal services, a browser extension for real-time protection, and comprehensive family-oriented educational content. The platform addresses a critical market need for accessible cybersecurity solutions beyond traditional corporate offerings.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Brand Identity & Design
The platform features a premium, clean design utilizing a dark teal, deep teal, and orange color palette with Sora typography. UI elements include pill-shaped buttons, split-layout banners, and diverse human imagery. The homepage emphasizes an emotional hero section, data statistics, content previews, and audience-specific pathways. Dedicated hubs for Kids, Seniors, Parents, Educators, and Small Businesses maintain distinct thematic designs. Animations are designed to respect reduced motion settings.

### Technical Implementation
The frontend is built with React 19, TypeScript, and Next.js App Router, with TanStack Query for state management and Tailwind CSS with shadcn/ui for styling. A zero-dependency `FadeIn` component (`client/src/components/fade-in.tsx`) using IntersectionObserver handles simple fade-in animations across 34 pages; framer-motion is only used by 2 pages (safety-score, training-lesson) that need `AnimatePresence`, plus shared components (hero-carousel, animated-threat-map), while React Hook Form with Zod manages form validation. **Wouter has been fully removed** — all client-side navigation now uses a Next.js navigation shim (`client/src/lib/navigation.tsx`) that provides wouter-compatible API signatures (`Link`, `useLocation`, `useParams`, `useSearch`, `useRoute`) backed by Next.js primitives (`next/link`, `next/navigation`). Next.js handles server-side rendering and routing with a comprehensive approach: **every route now has a dedicated App Router file** (~91 route files in the `app/` directory) providing proper `generateMetadata` with OG tags, canonical URLs, JSON-LD structured data, and appropriate robots directives. The catch-all `app/[...slug]/page.tsx` now only serves as a 404 handler. Dynamic detail pages (e.g., `app/guides/[slug]/page.tsx`) fetch data server-side from Express API for metadata generation and return 404 for non-existent slugs. Auth/admin/protected pages use `robots: { index: false, follow: false }` to prevent search engine indexing. **SSR refactored for crawlability:** 16 page files in `client/src/pages/` are true Server Components (no `"use client"`): home, about, accessibility, awareness-hub, browser-extension, cyber-hygiene, not-found, our-mission, parent-guide, privacy, quick-assessment, security, support-the-mission, support, terms, threat-trends. These render full HTML server-side so crawlers see real content including headings, text, links, and navigation. Interactive child components (BreachChecker, Navigation, HeroSection, newsletter forms, etc.) are client islands with their own `"use client"` directives. The remaining 64 pages keep `"use client"` due to direct hook usage (useQuery, useState, useForm, etc.) — auth/admin pages intentionally stay client-rendered. All components using React hooks, framer-motion, or browser APIs now have explicit `"use client"` at the component level. Client-side `useSEO()` and `SEOHead` removed from Server Component pages since `app/` route files handle metadata server-side. **ISR/Static generation** is configured: static content pages use `force-static`, content pages use `revalidate = 3600` (1-hour ISR), and admin/auth pages remain fully dynamic. The App shell (Toaster, ErrorBoundary, Analytics, DeziAssistant, etc.) is provided via `app/app-shell.tsx` in `layout.tsx`. This replaces the previous monolithic `client-app.tsx` approach — by importing only one page per route, Next.js compiles each page independently, avoiding OOM. All page content (Navigation, Hero, forms, accordions, etc.) renders as full HTML on the server and hydrates on the client. `App.tsx` is now a shell-only component (Toaster, ErrorBoundary, DeziAssistant, FeedbackWidget, CookieConsent, analytics) that accepts `children` — no routing logic remains. Legacy Vite infrastructure (server/vite.ts, server/static.ts, vite.config.ts, client/src/main.tsx, client/src/entry-server.tsx, client/index.html) has been fully deleted. The backend runs on Express 5 with Node.js and TypeScript as a custom server, providing REST endpoints and utilizing shared Zod schemas. Express handles `/api/*` routes, Next.js handles all page rendering. Authentication supports email/password, TOTP MFA, Passkeys (WebAuthn), and session management. Data persistence is handled by Drizzle ORM for PostgreSQL (Neon). Security measures include Helmet.js, multi-tier rate limiting, CSRF protection, payload limits, XSS/SQLi detection, secure cookies, input sanitization, Google reCAPTCHA, API anomaly detection, and GDPR-compliant cookie consent.

### Key Features
- **AI-Powered Tools**: Includes an AI Scam Analyzer capable of checking URLs, QR codes, screenshots, and SMS. It features a sophisticated Advanced Scam Intelligence Engine with capabilities like Campaign Playbook Engine (identifying multi-step attack patterns), Brand Sending Infrastructure Database, Context-Aware Analysis, Multi-Scan Campaign Correlation, Visual Template Analysis, Phantom Account Detection, and Context-Enhanced AI Prompts.
- **GCR Scam Guard Browser Extension**: A Chrome Manifest V3 extension providing real-time protection through auto-scanning, safety badges, lookalike domain detection, form submission warnings, URL reputation analysis, notification spam blocking, search result annotations, redirect chain detection, and clipboard hijack protection.
- **Dezi AI Assistant**: A persistent, floating widget powered by Anthropic Claude AI for interactive user support.
- **Content & Education**: Offers a Training Academy with audience-specific learning paths, an AI Prompt Library, comprehensive Cyber Safety Guides (including social media security), a Scam Intelligence Center, Cyber Threat Radar, and interactive hubs with gamified learning and scenario-based quizzes. All social media guides include AI-generated overview videos.
- **Explainer Videos**: AI-generated 1080p MP4 explainer videos are integrated across key pages for promotional and instructional purposes.
- **GCR Data Shield**: A personal data exposure scanner checking over 500 data brokers and HaveIBeenPwned databases. It provides a three-tier data removal system (guided, automated, continuous protection) and a Personal Data Vault with AES-256-GCM field-level encryption.
- **Identity Shield**: Generates cloaked-style masked identities (disposable emails, masked phone numbers, random usernames).
- **Security & Privacy Tools**: Includes a Data Broker Removal System, Breach Monitoring, Password Generator, and Family Safety Codeword Generator.
- **News Section**: Curates and simplifies cybersecurity news from 20 trusted RSS feeds using AI, with relevance scoring for families.
- **Automation & Governance**: Features automated weekly newsletters, AI content guardrails, automated threat intelligence, and a social distribution engine. The social engine utilizes a 3-tier content model (Guide-based evergreen, Reactive/breaking news, News Editorial) and integrates with Buffer for multi-platform publishing.
- **Engagement Discovery Engine**: Monitors cybersecurity RSS feeds, scores engagement opportunities, and generates AI-suggested comments for thought leadership.
- **Monthly Removal Reports**: Automated monthly HTML email reports detailing privacy scores and removal progress for subscribers.
- **Free Platform Model**: The platform is fully free — all pricing pages (/pricing, /gcr-guard-pricing, /data-shield-pricing, /checkout-success) redirect to the homepage. Pricing navigation items are permanently removed. All user-facing text reflects "everything is free" messaging. SignupEncouragementBanner is displayed on 13+ tool pages encouraging free account creation. The underlying tier system code remains intact but all user-facing language promotes free access. Stripe integration is retained but checkout is blocked by `isFreeAccessPeriod()` (active until Oct 2026).
- **Admin & SEO**: A comprehensive admin system with role-based access control, scan activity monitoring, an SEO keyword database, an internal linking engine, dynamic sitemap generation, and universal meta injection. All public pages are fully SSR for SEO and performance.
- **SEO & AEO Architecture**: FAQ schema (FAQPage JSON-LD) on all major pages (scam-checker, data-removal, kids, seniors, parents, password-generator, tools, faq, all /scams/ pages). NewsArticle schema on /news/ and /alerts/ articles with author, publisher, datePublished, dateModified. Organization schema includes sameAs social links. AI bots (GPTBot, ClaudeBot, PerplexityBot) are allowed via robots.txt for AEO. AhrefsBot and SemrushBot allowed for analytics. A reusable `RelatedResources` component (`client/src/components/related-resources.tsx`) provides internal cross-linking on hub pages (kids, seniors, parents) and tool pages (scam-checker, data-removal, password-generator).
- **Navigation Architecture**: A two-hub structure: Protection Hub (tools) and Learning Hub (educational content), with desktop dropdowns and mobile menus.
- **User Dashboard**: A product-aware dashboard displaying a safety score, activity statistics, product status cards, quick actions, recent scans, regional threats, and threat intelligence. Includes a post-signup onboarding checklist.
- **Account Settings**: Comprehensive account management including profile editing, password changes, and MFA status.
- **Auth Flow**: Structured post-registration steps and clear login/email verification redirects.
