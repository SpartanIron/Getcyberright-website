# GetCyberRight - Cybersecurity Education Platform

## Overview
GetCyberRight is a family-focused cybersecurity education platform dedicated to providing practical knowledge to non-technical users such as families, parents, children, and seniors. It aims to simplify cybersecurity through interactive safety assessments, real-time threat intelligence, and educational content. The platform offers essential tools, with a vision to become a leading, accessible cybersecurity education resource for everyone, addressing those often overlooked by traditional corporate solutions. Key capabilities include AI-powered scam detection, data broker removal, a browser extension for real-time protection, and comprehensive family-oriented educational content.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Brand Identity & Design
The platform features a premium, clean design with a color palette of dark teal, deep teal, and orange. Typography uses Sora for all text. UI elements include pill-shaped buttons, split-layout banners, and diverse human imagery. The homepage emphasizes an emotional hero section, data statistics, content previews, and audience-specific pathways. Dedicated hubs for Kids, Seniors, Parents, Educators, and Small Businesses maintain distinct themes. All animations are designed to respect reduced motion settings.

### Technical Implementation
The frontend is built with React 19, TypeScript, and Vite, utilizing Wouter for routing, TanStack Query for state management, and Tailwind CSS with shadcn/ui for styling. Framer Motion manages animations, while React Hook Form with Zod handles form management and validation. The design is mobile-first with dynamic SEO. **Vite SSR (Server-Side Rendering)** is implemented for all public pages to ensure fully rendered HTML delivery, enhancing performance and SEO. The backend uses Express 5 on Node.js with TypeScript, providing REST endpoints and shared Zod schemas for validation. Authentication supports email/password, TOTP MFA, Passkeys (WebAuthn), and session management. Data is managed with Drizzle ORM for PostgreSQL (serverless via Neon). Security measures include Helmet.js, multi-tier rate limiting, CSRF protection, payload limits, XSS/SQLi detection, secure cookies, input sanitization, Google reCAPTCHA, and API anomaly detection. A GDPR-compliant cookie consent banner is also integrated.

### Key Features
- **AI-Powered Tools**: Includes an AI Scam Analyzer, Scam Checker (for URLs, QR codes, screenshots, and SMS validation), deepfake/AI voice scam awareness, scan history, shareable reports, community scam reporting, and Scam of the Week alerts. All scans (both anonymous and authenticated) are recorded to the `scan_history` database table via `/api/scam-check/*` endpoints (url, phone, email-headers, analyze). The `/api/scan-stats` endpoint returns total scan counts across all tables. The Dezi hero on the homepage uses these endpoints with correct `apiRequest(method, url, data)` signature.
- **GCR Scam Guard Browser Extension**: A Chrome Manifest V3 extension providing auto-scan on page load, real-time safety badges, lookalike domain detection, form submission warnings, enhanced URL reputation analysis, notification spam blocking (intercepts `Notification.requestPermission` and blocks known spam domains), search result safety annotations (inline badges on Google/Bing/DuckDuckGo/Yahoo results), redirect chain detection (flags multi-hop cross-domain redirects), and clipboard hijack protection (detects crypto address swapping). New threat vectors are gated behind `essential`+ tier.
- **Dezi AI Assistant**: A persistent, floating widget powered by Anthropic Claude AI for interactive support.
- **Content & Education**: Offers a Training Academy with audience-specific learning paths, AI Prompt Library, Cyber Safety Guides, Scam Intelligence Center, Cyber Threat Radar, and interactive hubs for various audiences with gamified learning and scenario-based quizzes.
- **GCR Data Shield**: A personal data exposure scanner that checks 500+ data brokers and HaveIBeenPwned databases. It features a three-tier data removal system: guided self-removal, automated opt-out request submission, and continuous protection with monthly re-scans. The Personal Data Vault uses AES-256-GCM field-level encryption for all sensitive PII (names, emails, phone numbers, addresses, DOB, relatives, employers). Encryption key stored in `VAULT_ENCRYPTION_KEY` env var. All vault access is audit-logged to `vault_audit_logs` table with user, action, IP, and timestamp. A zero-knowledge vault key infrastructure (Bitwarden model) is deployed: on login, a per-user DEK (Data Encryption Key) is derived via PBKDF2 (600k iterations) from the user's password and stored encrypted server-side in `user_vault_keys` table. The DEK is decrypted client-side and held in sessionStorage (cleared on logout/tab close). Client crypto module: `client/src/lib/vaultCrypto.ts`. Server vault key endpoints: GET/POST `/api/vault-keys`, POST `/api/vault-keys/rotate`.
- **Identity Shield** (`/identity-shield`): Cloaked-style masked identity generation. Creates disposable email aliases (`@shield.getcyberright.com`), masked phone numbers, and random usernames for sign-ups. Real values encrypted with AES-256-GCM (`enc:v1:` prefix). Tier limits: free/scan=2, essential/remove=10, professional/protect=50, enterprise=200. Full CRUD API at `/api/masked-identities/*`. Frontend dashboard with alias management, copy-to-clipboard, forwarding toggles, activity logs, and service categorization. Backend service: `server/maskedIdentityService.ts`. DB tables: `masked_identities`, `masked_identity_activity`, `notification_threats`.
- **Security & Privacy**: Provides a Data Broker Removal System, Breach Monitoring, Password Generator, and Family Safety Codeword Generator.
- **News Section**: Curates cybersecurity news from 20 trusted RSS feeds, simplified by AI for families. It includes a relevance scoring system to filter irrelevant content and prioritize actionable stories.
- **Automation & Governance**: Features automated weekly newsletters, AI content guardrails, automated threat intelligence, and a social distribution engine. The trend-aware social engine posts 7 days a week with themed content pillars: Monday (Start Your Week Safe), Tuesday (Threat Alert), Wednesday (Practical Protection), Thursday (Myth Buster), Friday (Quick Tips), Saturday (Weekend Safety Roundup), Sunday (Family Focus). Breaking news override threshold is urgency >= 3 with medium or high impact. Posts via Buffer to LinkedIn, Facebook, and Instagram with platform-specific posting windows. Social post images use a three-tier cascade with branded overlays: 1) real article thumbnail from the source RSS feed (downloaded, validated, branded with overlay at 1200x630 and 1080x1080), 2) AI-generated photorealistic image with branded overlay when no source image exists, 3) branded SVG text card as fallback. The branded overlay composites a gradient bottom bar, headline text, subtext in accent color, top/bottom accent strips, and the GetCyberRight logo using Sharp SVG compositing over the real photo background. Each template style (stat_card, tip_card, alert_card, insight_card, quote_card) uses its own accent color palette. Instagram images are 1080x1080 square with adjusted typography. RSS feeds use retry logic (2 retries with backoff) and 30s timeout. Image downloads include SSRF protection, size limits (10MB), and dimension validation.
- **Monthly Removal Reports**: Automated monthly HTML email reports for subscribers detailing privacy scores, removal progress, and exposed data categories.
- **Independent Subscription Products**: GCR Scam Guard and GCR Data Shield are separate subscription products with independent Stripe products, pricing, and tier tracking. Users can subscribe to one, both, or neither independently.
  - **GCR Scam Guard** (`/gcr-guard-pricing`): Free / Pro $4.99/mo ($3.99 annual) / Family $7.99/mo ($5.99 annual). Stripe keys: `sg_essential_monthly`, `sg_essential_annual`, `sg_professional_monthly`, `sg_professional_annual`. Stored in `subscriptionTier` + `subscriptionExpiresAt` DB fields.
  - **GCR Data Shield** (`/data-shield-pricing`): Scan (Free) / Essential $8.99/mo ($6.99 annual) / Professional $14.99/mo ($11.99 annual). Stripe keys: `ds_essential_monthly`, `ds_essential_annual`, `ds_professional_monthly`, `ds_professional_annual`. Stored in `shieldSubscriptionTier` + `shieldSubscriptionExpiresAt` DB fields.
  - Stripe products use `gcr_product` and `gcr_tier` metadata to route webhook events to correct DB fields. The `/api/subscription/status` endpoint returns both `tier` (Scam Guard) and `shieldTier` (Data Shield).
  - **Bundle Plans** (`/pricing`): Complete Protection $11.99/mo ($8.99 annual) = SG Pro + DS Essential; Total Protection $18.99/mo ($13.99 annual) = SG Family + DS Professional. Stripe keys: `bundle_complete_monthly`, `bundle_complete_annual`, `bundle_total_monthly`, `bundle_total_annual`. Bundles set both `subscriptionTier` and `shieldSubscriptionTier` simultaneously via `applySubscriptionUpdate()`.
- **Competitive Positioning**: Individual pricing pages include competitor comparison tables, stat highlight cards, and updated FAQ. Both link to `/pricing` for bundle deals.
- **Annual Billing**: All pricing pages feature a Monthly/Annual billing toggle with ~17-23% annual discount. The checkout endpoint accepts `returnPath` for source-aware cancel URLs.
- **Admin & SEO**: A comprehensive admin system with role-based access control, scan activity monitoring (data broker scans + scam checks), admin password reset for user accounts, SEO keyword database, internal linking engine, dynamic sitemap generation, and universal meta injection for enhanced search engine visibility.
