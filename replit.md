# GetCyberRight - Cybersecurity Education Platform

## Overview
GetCyberRight is a family-focused cybersecurity education platform providing practical knowledge to non-technical users, including families, parents, kids, seniors, and everyday people. Its purpose is to simplify complex cybersecurity information through interactive safety assessments, real-time threat intelligence, and audience-specific educational content. The project's vision is to cover those underserved by corporate cybersecurity, with core tools free to get started.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Brand Identity & Design
The platform uses an enterprise teal and orange color scheme with a flat, minimal aesthetic, prioritizing accessibility, SEO, and print support. Audience-specific hubs (Kids, Seniors, Parents, Educators, Small Business) feature distinct color themes while maintaining brand consistency. The Kids Digital Safety Hub offers age-segmented, gamified lessons with colorful cartoon illustrations on every card and lesson view. The homepage features an enhanced cinematic hero with Ken Burns slow zoom/pan on a diverse family image, rotating audience-specific subtext (cycling through 5 messages every 3.5s), dual CTAs ("Check If It's a Scam" + "Explore Free Tools"), gradient-animated "Get CyberRight." headline text (teal-to-orange shimmer), animated trust stats bar with count-up numbers (500+ brokers, 406+ prompts, 6 feeds, $0 Free to Get Started), trust line ("Protecting families across 13 regions worldwide"), and a subtle hero background glow effect. All page cards (Tools, Parents, Seniors, Small Business, Educators, Training) feature image-backed cards with dark gradient overlays (h-48 mobile / h-56 desktop). About page uses two-column image+text storytelling, 3 principle cards with icons, and a CTA section with background image behind teal overlay. All animations respect prefers-reduced-motion. Em dashes are prohibited in all user-facing content. All human images must feature diverse multiracial people.

### Technical Implementation
- **Frontend**: React 19 with TypeScript and Vite, Wouter for routing, TanStack Query for state management, Tailwind CSS with shadcn/ui for styling, Framer Motion for animations, and React Hook Form with Zod for forms. It features a mobile-first design with dynamic SEO management.
- **Backend**: Express 5 on Node.js with TypeScript (ES modules), employing REST endpoints with robust input validation using shared Zod schemas.
- **Authentication**: A custom system supporting email/password, TOTP MFA, backup codes, session management, email verification, password reset, and Passkeys (WebAuthn).
- **Data Layer**: Drizzle ORM for PostgreSQL (serverless via Neon), using `drizzle-zod` for automatic Zod schema generation across 53 key tables.
- **Security**: Helmet.js for security headers, multi-tier rate limiting, CSRF protection with timing-safe token validation, payload limits, XSS/SQLi detection, secure cookie settings, input sanitization, and Google reCAPTCHA. It includes API anomaly detection, centralized Winston logging, and compliance mapped to OWASP ASVS, CIS Controls, ISO 27001, NIST 800-53, and MITRE ATT&CK. An admin dashboard provides real-time security monitoring and audit logging. Session fixation protection via `req.session.regenerate()` on login and MFA verification. Cryptographically secure OTP generation via `crypto.randomInt()`. Timing-safe comparison for backup codes and password reset tokens via `crypto.timingSafeEqual()`. SSRF protection in thumbnail service with internal IP blocking and redirect validation. Mass assignment prevention via Zod schema validation on all PATCH endpoints and field whitelisting on vault routes. Rate limiting applied to all state-changing endpoints including gamification, training, data removal, and admin content generation. Dezi AI chat endpoints are hardened with: rate limiting (30 AI messages/hour, 100 reads/15min), session-based conversation isolation, input sanitization with length limits (4000 chars), prompt injection protection via XML delimiters on user messages, OCR text sandboxing, conversation limits (50 messages, 10 conversations per session), max_tokens cap (1024), and 5MB file upload limit.

### Key Features
- **AI Scam Analyzer**: OpenAI-powered tool for threat analysis of messages, emails, headers, and URLs.
- **Scam Checker**: Comprehensive analysis of URLs, QR codes, images, phone numbers, and email headers using multiple engines and AI.
- **AI Prompt Library & Management System**: 406+ expert-crafted AI prompts across 8 categories (safety, productivity, finance, communication, learning, health, work, tech) with automated weekly review and improvement suggestions via Claude, and admin approval workflows. Prompts use advanced prompt engineering: role assignment, chain-of-thought reasoning, structured output formatting, and safety guardrails.
- **Dezi AI Assistant**: A floating chat widget offering real-time scam analysis, password generation, phishing education, and region-aware security resources.
- **Data Broker Removal System**: Enterprise-grade system for automated personal data removal from 501+ data broker sites, featuring an encrypted data vault, exposure scanning, automated opt-out content generation, and AI-driven privacy automation for identity risk scoring and removal queue management. Refactored from a single 3939-line file into 13 focused components in `client/src/components/data-removal/`. The page uses a guided scan-first journey flow (Vault → Scan → Remove → Monitor) instead of tabs, with progress celebration after removals. All features are free to get started.
- **AI Content Guardrails**: Ensures truthfulness, verifiability, and quality for AI-generated content.
- **Automated Weekly Newsletter System**: AI-powered content generation and scheduled sending.
- **Training Academy**: Audience-specific learning paths with modules, lessons, quizzes, and certificates.
- **Breach Monitoring**: Automated breach checking and subscription-based monitoring.
- **Password Generator**: Interactive tool for secure password creation.
- **Audio/Voice Deepfake Detector**: Analyzes audio for deepfake indicators.
- **Family Safety Codeword Generator**: Generates secure codewords for emergency verification.
- **Gamification & Achievement System**: Includes badge definitions, user badges, and progress tracking.
- **Dynamic Trending Threats**: AI-powered, geo-tagged threat alerts on the homepage that auto-refresh every 6 hours using Claude Haiku. Threats are region-specific (13 regions including US, EU, West/East/Southern Africa, South/Southeast Asia) and audience-targeted (seniors, families, children, general). Uses timezone-based geo-detection on the frontend. Admin can manually trigger AI refresh or add threats manually. Em dashes are sanitized from all content. Schema: `trending_threats` table with regions array, audience, severity, auto-expiration.
- **Regional Scam Profiles**: Visually rich "Common Scams in Your Area" card grid on homepage with auto-detected region (timezone-based). Covers 11 regions (US, UK, CA, AU, EU, AF, South Asia, Southeast Asia, Latin America, NZ, Global) with 4-6 region-specific scam profiles each displayed as image-backed cards with category illustrations, severity-colored borders/badges, and protective tips. Responsive 1/2/3-column grid layout. Region picker dropdown for manual override. Data in `shared/regions.ts` (REGIONAL_SCAM_PROFILES). Dezi AI assistant enhanced with region-aware scam guidance in system prompt.
- **Automated Threat Intelligence**: Ingests data from 8 trusted sources (URLhaus, PhishTank, CISA, NVD, HIBP).
- **Automated Content Governance System**: Monitors educational content for freshness and relevance.
- **User Feedback System**: Floating feedback widget (bottom-left) on every page with 5 categories (bug, feature, question, praise, other). No login required. Submissions stored in `user_feedback` table. Admin email notification via Resend on each submission. Admin dashboard at `/admin/feedback` for reviewing, filtering by status (new/in_progress/resolved/dismissed), adding internal notes, and replying via email.
- **Programmatic Scam Pages**: 17 SEO-optimized scam guide pages at `/scams/:scamType` (PayPal, Amazon, Facebook, romance, crypto, tech support, phishing, Instagram, WhatsApp, job, delivery, Zelle, shopping, grandparent, social media, identity theft, data breach). Each page includes overview, how-it-works steps, warning signs, real example messages, prevention steps, and FAQ. All pages have BlogPosting + FAQPage + BreadcrumbList structured data. Content in `shared/scam-content.ts`.
- **SEO Keyword Database**: 300 keywords across 10 clusters (identity theft, online scams, phishing, seniors, kids, password security, privacy, device security, data breaches, social media security) with cluster relationships for internal linking. Data in `shared/seo-keywords.ts`.
- **Internal Linking Engine**: `RelatedContent` component (`client/src/components/related-content.tsx`) auto-generates related page links based on keyword cluster relationships and content cross-references. Used on programmatic scam pages.
- **Dynamic Sitemap**: Server-generated `sitemap.xml` with 56+ URLs including all static pages, programmatic scam pages, and dynamically published guides, alerts, and scam intelligence pages. Includes changefreq and priority values.
- **BlogPosting Schema**: Added to structured data system for content pages with articleSection, keywords, and wordCount support.
- **Cyber Safety Guides System**: Database-driven article publishing engine (`cyber_safety_guides` table) with SEO title, meta description, structured headings, table of contents, FAQ section, schema markup, and 1500-2000 word targets. Supports AI-generated and manually authored guides. Public API at `/api/guides` and `/api/guides/:slug`. Admin CRUD at `/api/admin/guides`.
- **Scam Intelligence Center**: Enhanced scam database (`scam_intelligence` table) for auto-generated scam pages with fields for scam_name, scam_category, platform_used, target_audience, example_messages, warning_signs, prevention_tips, how_it_works, risk_level, and FAQ. Public API at `/api/scam-intel` and `/api/scam-intel/:slug`. Admin CRUD at `/api/admin/scam-intel`. Supports 1000+ scam pages.
- **Cyber Threat Radar**: Monitoring system (`cyber_threat_alerts` table) for emerging cyber threats with threat_name, threat_category, risk_level, affected_platforms, indicators, mitigation_steps, CVE IDs, and region targeting. Public API at `/api/alerts` and `/api/alerts/:slug`. Admin CRUD at `/api/admin/threat-alerts`. Alert pages at `/alerts/[threat-name]`.
- **Content Automation Engine**: AI-powered article generation pipeline (`server/contentAutomationService.ts`) using Claude. Workflow: keyword -> article draft -> SEO optimization -> internal linking -> publish. Target: 3-5 articles per week. Includes SEO scoring, automatic related content linking, and unused keyword tracking. Admin API at `/api/admin/content-automation/generate` and `/api/admin/content-automation/stats`.
- **Social Distribution Engine**: Automated social post generation (`social_posts` table, `server/socialDistributionService.ts`) when content is published. Generates LinkedIn posts, X/Twitter threads, and short alert messages with hashtags. Admin API at `/api/admin/social-distribution/generate` and `/api/admin/social-distribution/stats`.
- **Growth Orchestrator**: Central automation service (`server/growthOrchestrator.ts`, `growth_tasks` table) coordinating all platform modules. Schedules article generation (Mon/Wed/Fri), triggers scam page creation, monitors threat feeds, publishes alert pages, generates social posts, and maintains internal linking. Processes tasks every 15 minutes. Dashboard API at `/api/admin/growth/dashboard`. Task management at `/api/admin/growth/tasks` and `/api/admin/growth/schedule-task`.
- **Platform Growth Metrics**: Daily metrics snapshots (`platform_metrics` table) tracking articles published, keywords covered, scam pages generated, alerts generated, social posts created, subscriber growth, and tool usage. API at `/api/admin/growth/metrics`.
- **Admin System**: Comprehensive admin dashboard for user management, security monitoring, threat intelligence, content governance, AI prompt management, trending threat management, user feedback management, content automation, social distribution, and growth orchestration.
