You are a senior cybersecurity architect and distributed systems engineer.

Build a production-grade intelligence platform called:

"GetCyberRight Data Shield + Scam Guard Engine"

This system must operate at scale, ingest multiple OSINT and breach data sources, and deliver reliable, low-noise risk intelligence.

---

## 🎯 SYSTEM OBJECTIVE

Design a scalable backend that:

- Accepts identity inputs (email, phone, domain, username)
- Continuously ingests and updates exposure data
- Correlates signals across multiple intelligence sources
- Produces accurate, explainable risk scores
- Minimizes false positives
- Supports real-time and batch processing

---

## 🧱 CORE ARCHITECTURE (MANDATORY)

### 1. MICROSERVICES DESIGN

Split into services:

- ingestion-service
- osint-service
- breach-service
- darkweb-service
- threat-intel-service
- scoring-service
- api-gateway

Each service must:
- Run independently
- Communicate via message queue
- Be containerized (Docker)

---

### 2. MESSAGE QUEUE (REQUIRED)

Use:
- Kafka (preferred) OR Redis Streams

Purpose:
- Decouple ingestion from processing
- Enable retry + fault tolerance
- Support async pipelines

---

### 3. DATA STORAGE STRATEGY

Use polyglot persistence:

- PostgreSQL → structured identity + results
- Elasticsearch → search + breach indexing
- Redis → caching + rate limiting

Schema must support:
- identity graph relationships
- time-series exposure tracking
- deduplication

---

### 4. BREACH DATA ENGINE (NO HIBP)

- Build ingestion pipelines for public breach datasets
- Normalize all data into canonical format
- Deduplicate using:
  - email hash
  - breach source
  - timestamp

- Implement:
  - full-text search
  - partial match (username reuse)

---

### 5. OSINT ENGINE

Integrate:
- SpiderFoot (as orchestrator module)
- Recon-ng
- theHarvester

Wrap each tool in a service adapter:
- Standardize output format
- Enforce timeout limits
- Handle failures gracefully

---

### 6. DARK WEB MONITORING ENGINE

Implement:

- Tor crawler service
- Paste monitoring service
- Scheduled crawling jobs

Features:
- keyword indexing
- content fingerprinting
- duplicate detection

---

### 7. THREAT INTELLIGENCE ENGINE

Integrate:

- OpenCTI (self-hosted if possible)
- MISP (self-hosted or API)
- Pulsedive (free API)

Enrichment:
- malicious domains
- phishing indicators
- IP reputation

---

### 8. SCAM DETECTION ENGINE

Build a rule-based + heuristic system:

Inputs:
- phone
- email
- domain

Checks:
- domain age (WHOIS)
- typosquatting detection
- scam keyword patterns
- frequency of reports

Output:
- scam_likelihood
- confidence_score
- explanation

---

### 9. RISK SCORING ENGINE (CRITICAL)

Must be:

- deterministic
- explainable
- tunable

Factors:
- breach_count (weighted by recency)
- password exposure
- dark web presence
- scam signals
- threat intel matches

Output:
{
  "risk_score": 0-100,
  "risk_level": "Low/Medium/High",
  "explanation": []
}
