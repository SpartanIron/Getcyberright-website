Act as a senior full-stack engineer and enterprise UI/UX designer.

Objective:
Rebuild www.getcyberright.com to achieve enterprise-grade visual polish, UX clarity, performance, and trust comparable to KnowBe4.com, while keeping the tone human-friendly and accessible to non-technical users, families, seniors, and small businesses.

Tech Stack (Mandatory):
- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion (subtle animations only)
- TypeScript
- SEO-friendly, server-side rendering
- Mobile-first, responsive design
- Accessibility (WCAG-aware, semantic HTML)

DO NOT use:
- Page builders
- Inline CSS
- Random component libraries
- Over-engineered animations
- Dark patterns or aggressive popups

--------------------------------------------------
DESIGN SYSTEM (CREATE FIRST)
--------------------------------------------------

1. Typography
- Primary font: Inter (or system sans fallback)
- Headline scale: clear visual hierarchy (H1–H5)
- Body text optimized for readability (16–18px base)
- Line length max 70–75ch

2. Color System
- Primary brand color (used only for CTAs)
- Neutral background palette (white / soft gray)
- High-contrast text for trust and accessibility
- Minimal accent usage

3. Spacing & Layout
- Consistent vertical rhythm
- Max-width container (1200–1280px)
- Section padding large and breathable
- Grid-based alignment

4. UI Components (Reusable)
- Primary / secondary CTA buttons
- Section container
- Feature cards
- Trust badges row
- Testimonial block
- Footer with structured links

--------------------------------------------------
SITE STRUCTURE
--------------------------------------------------

Navigation (sticky):
- Solutions
- Free Tools
- Resources
- About
- Contact
Primary CTA in nav: “Get Free Protection Tools”

--------------------------------------------------
HOMEPAGE (CRITICAL)
--------------------------------------------------

Build the homepage FIRST. Do not create additional pages until this feels premium.

Homepage Sections:

1. Hero Section (Above the Fold)
- Clear, human-readable value proposition
- Headline example:
  “Protecting people and businesses from modern cyber scams”
- Subheadline:
  “Simple, practical cybersecurity education and tools for families, seniors, and organizations”
- Primary CTA: “Get Free Protection Resources”
- Secondary CTA (text-only): “Learn How Scammers Operate”
- Calm, professional visual tone

2. Trust Signals
- Placeholder logos or text badges
- Language emphasizing credibility, education, and safety

3. Problem → Solution Flow
- Identify real-world scam risks (phishing, romance scams, identity theft)
- Show how GetCyberRight simplifies protection
- Focus on reassurance, not fear

4. Feature Blocks
- Modular cards with icons
- Plain-language explanations
- Benefits over features

5. Education & Resources
- Highlight free tools, guides, and learning materials
- Position GetCyberRight as a trusted educator

6. Social Proof
- Testimonials or quotes (use placeholders)
- Emphasize peace of mind and clarity

7. Strong Closing CTA
- Reiterate mission
- Primary CTA repeated
- Calm confidence, no urgency pressure
