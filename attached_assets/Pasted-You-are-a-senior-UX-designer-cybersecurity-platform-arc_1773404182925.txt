You are a senior UX designer, cybersecurity platform architect, and front-end engineer.

You are working on the website GetCyberRight.

Your task is to redesign the homepage into a visual cybersecurity authority hub that improves clarity, trust, and usability.

IMPORTANT RULE:

Do NOT completely replace the current UI design system.

You may enhance the interface using image-rich sections, tiles, and visual components while maintaining the current style and color palette.

The homepage must remain fast, accessible, and easy to scan.

--------------------------------------------------

PRIMARY HOMEPAGE OBJECTIVES

The homepage must instantly communicate:

1. What the platform does
2. Who it helps
3. Why it matters
4. What the visitor should do next

The homepage should reduce cognitive overload by using large visual sections and tile navigation.

--------------------------------------------------

HERO SECTION

Create a strong hero section.

Headline:

Protect Yourself From Online Scams, Identity Theft, and Digital Threats

Subheadline:

Learn how to recognize scams, protect your personal data, and stay safe online.

Primary actions:

Check a Scam  
Protect Your Data  
Learn Cyber Safety

Use a large background illustration related to cybersecurity awareness.

--------------------------------------------------

CORE TILE NAVIGATION

Add a large visual tile grid immediately below the hero.

Tiles must include icons or illustrations.

Tile categories:

Online Scams  
Identity Theft  
Cyber Safety Guides  
Privacy Protection  
Cybersecurity Tools  
Threat Alerts

Each tile links to the relevant section of the platform.

Tiles should be large, visually clear, and easy to scan.

--------------------------------------------------

LATEST SCAM ALERTS SECTION

Create a section highlighting recent scam alerts.

Display alerts as cards with:

alert title  
risk level indicator  
short description  
link to full page

Include visual indicators:

High Risk (red badge)  
Medium Risk (orange badge)  
Low Risk (green badge)

--------------------------------------------------

CYBER SAFETY GUIDES SECTION

Show featured guides in a card layout.

Each card includes:

image  
title  
short description  
read more link

Example guides:

How to Prevent Identity Theft  
How to Detect Phishing Emails  
Protecting Seniors From Scams  
Online Privacy Protection Guide

--------------------------------------------------

CYBERSECURITY TOOLS SECTION

Highlight interactive tools using icon cards.

Tools may include:

Password Strength Checker  
Scam Message Analyzer  
Email Breach Checker  
Privacy Checklist Generator

Each tool card should explain its purpose clearly.

--------------------------------------------------

SCAM INTELLIGENCE CENTER PREVIEW

Add a preview section explaining the scam database.

Display sample scams such as:

PayPal phishing scam  
Facebook marketplace scam  
Crypto investment scam

Each card links to a scam explanation page.

--------------------------------------------------

CYBER AWARENESS SECTION

Add an educational section using infographics.

Examples:

How phishing attacks work  
How identity theft happens  
Top online scams

Use visuals to simplify complex concepts.

--------------------------------------------------

TRUST AND MISSION SECTION

Create a credibility section explaining the purpose of GetCyberRight.

Include:

mission statement  
educational purpose  
commitment to cybersecurity awareness

Emphasize helping families and individuals stay safe online.

--------------------------------------------------

EMAIL SUBSCRIPTION SECTION

Add a call-to-action for users to subscribe.

Offer:

Free Digital Safety Guide for Families

Explain what subscribers receive:

cyber safety tips  
scam alerts  
security advice

--------------------------------------------------

FOOTER KNOWLEDGE HUB

Add structured navigation in the footer.

Sections:

Cyber Safety Guides  
Scam Database  
Threat Alerts  
Cybersecurity Tools  
Privacy Protection Resources

--------------------------------------------------

VISUAL DESIGN RULES

The homepage should prioritize visual clarity.

Use:

large tiles  
clear icons  
infographic-style explanations  
consistent spacing

Avoid long text blocks.

--------------------------------------------------

IMAGE PERFORMANCE REQUIREMENTS

All images must:

use modern formats such as WebP or AVIF  
be compressed under 200 KB  
use lazy loading  
be responsive

The homepage must remain fast and optimized.

--------------------------------------------------

ACCESSIBILITY

Ensure accessibility for all users.

Include:

descriptive alt text  
clear color contrast  
readable typography

--------------------------------------------------

FINAL OUTPUT

Produce a homepage structure that includes:

visual tile navigation  
image-rich guide cards  
scam alert cards  
tool cards  
infographic sections  
clear calls-to-action

The homepage should feel like a major cybersecurity knowledge platform while maintaining the current design identity.
