Act as a senior full-stack engineer, enterprise UI/UX designer, and security-focused product architect.

Objective:
Build a complete, production-ready, full-stack website for www.getcyberright.com with visual polish, UX clarity, trust signals, and performance comparable to KnowBe4.com. The site must be accessible to non-technical users, families, seniors, educators, and small businesses while still feeling enterprise-grade and authoritative.

The final result should feel calm, trustworthy, modern, and professional — not flashy, not technical, not cluttered.

--------------------------------------------------
TECH STACK (MANDATORY)
--------------------------------------------------

Frontend:
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion (subtle motion only)

Backend:
- Next.js API routes (server actions where appropriate)
- PostgreSQL (or SQLite for dev)
- Prisma ORM
- Secure form handling (contact, newsletter)

Infrastructure:
- Environment variables
- SEO-friendly SSR
- Accessible semantic HTML
- Mobile-first responsive design

DO NOT use:
- Page builders
- Inline styles
- Random UI libraries
- Over-animated effects
- Dark patterns or aggressive popups

--------------------------------------------------
DESIGN SYSTEM (CREATE FIRST)
--------------------------------------------------

Define a global design system before building pages.

1. Typography
- Primary font: Inter
- Clear hierarchy (H1–H5)
- Body text optimized for reading (16–18px)
- Line length capped at ~70ch

2. Color Tokens
- Primary brand color (used ONLY for CTAs)
- Neutral background palette (white / light gray)
- High-contrast text for accessibility
- Muted accent color for highlights

3. Spacing & Layout
- Consistent vertical rhythm
- Max-width container (1200–1280px)
- Large section padding for visual calm
- Grid-based alignment

4. Reusable Components
- Header with sticky navigation
- Mega-menu capable nav structure
- CTA button variants
- Card components
- Section wrappers
- Trust badge row
- Testimonial block
- Footer with structured links
