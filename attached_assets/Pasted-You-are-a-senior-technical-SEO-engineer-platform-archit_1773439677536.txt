You are a senior technical SEO engineer, platform architect, and cybersecurity content strategist working on the website GetCyberRight.

Your task is to dramatically increase the site's **indexable depth** so search engines can crawl, index, and rank hundreds or thousands of cybersecurity pages.

The site currently contains major platform modules such as Cyber Safety Guides, Scam Intelligence, Threat Radar, Cybersecurity Tools, and an Education Hub.

Your objective is to ensure that every module generates **search-engine-visible pages with unique URLs and crawlable content**.

---

PRIMARY OBJECTIVE

Transform the platform into a **large-scale, indexable cybersecurity knowledge graph**.

Target scale:

* 500+ educational guides
* 1000+ scam intelligence pages
* continuous threat alert pages
* tool pages
* supporting FAQ pages

---

CRAWLABLE URL STRUCTURE

Ensure the website generates clean, static, crawlable URLs.

Example structure:

/guides/how-to-prevent-identity-theft
/guides/how-to-detect-phishing-emails
/scams/paypal-phishing-scam
/scams/facebook-marketplace-scam
/scams/crypto-investment-scam
/alerts/new-paypal-phishing-campaign
/tools/password-strength-checker
/tools/scam-message-analyzer

Every page must have a unique URL that can be indexed by search engines.

---

SERVER-SIDE RENDERING

Ensure all pages render content server-side so search engine crawlers can read them.

Avoid client-side-only rendering that hides content from crawlers.

All pages must return full HTML with visible content.

---

PROGRAMMATIC SEO ENGINE

Create a programmatic page generation system that builds pages from databases.

Examples:

scam database → generate scam pages
threat alerts database → generate alert pages
keyword database → generate guide pages

Each generated page must contain:

SEO title
meta description
structured headings
content sections
FAQ
internal links

---

SITEMAP GENERATION

Automatically generate sitemap.xml including every page type:

guides
scams
alerts
tools
resources

Update sitemap automatically when new pages are created.

---

ROBOTS AND CRAWL RULES

Ensure robots.txt allows search engines to crawl all knowledge sections:

/guides/
/scams/
/alerts/
/tools/

Block only admin or private routes.

---

INTERNAL LINKING NETWORK

Automatically connect related pages.

Examples:

identity theft guide → identity theft scam pages
phishing guide → phishing scam pages
scam pages → scam detection tool
alert pages → related guides

This creates a dense internal linking structure that helps search engines understand topic authority.

---

CATEGORY HUB PAGES

Create index pages for each topic cluster.

Example hub pages:

/identity-theft
/phishing
/online-scams
/password-security
/privacy-protection

Each hub page lists all related guides and scam pages.

---

STRUCTURED DATA

Add JSON-LD schema to help search engines understand content.

Use:

Article
FAQPage
HowTo
Dataset
BreadcrumbList
Organization

---

CONTENT DEPTH

Each page should contain at least:

800–2000 words depending on page type.

Scam pages must include:

scam overview
example scam messages
warning signs
who is targeted
prevention steps
FAQ

---

DISCOVERABILITY

Ensure every new page is discoverable through:

navigation
category hubs
internal links
XML sitemap

No orphan pages should exist.

---

INDEXING VALIDATION

Create a system that periodically checks:

which pages are indexed
which pages are not indexed

Automatically report pages needing optimization.

---

SCALABILITY

The architecture must support expansion to:

2000+ pages without structural redesign.

---

FINAL OUTPUT

Generate:

programmatic SEO architecture
URL routing rules
sitemap generator
internal linking engine
category hubs
schema markup modules
indexing validation system

The goal is to transform GetCyberRight into a **deep, crawlable cybersecurity authority platform** with hundreds of indexable pages.
