Act as a senior UX architect, visual designer, and full-stack engineer.

Objective:
Implement a consistent, enterprise-grade page banner system across the entire website, excluding the homepage, which already has its own hero section.

The banner system must provide visual continuity, clear page orientation, and a polished, trust-forward introduction for every internal page.

--------------------------------------------------
SCOPE (CRITICAL)
--------------------------------------------------

- Apply this banner system to ALL pages
- Explicitly EXCLUDE the homepage (/)
- Do NOT modify the homepage hero section

--------------------------------------------------
GLOBAL BANNER REQUIREMENT
--------------------------------------------------

Every internal page must begin with a page banner.

No exceptions.
No internal page should start directly with body content.

--------------------------------------------------
BANNER COMPOSITION
--------------------------------------------------

Each banner must include:

1. High-Quality Visual
- A professional, high-resolution image
- Image occupies either the left or the right side of the banner
- Orientation may alternate by page but must be intentional
- Images must be contextually relevant to the page topic
- No generic, cliché, or low-quality stock imagery
- Calm, realistic, human-centered visuals preferred

2. Page-Specific Title Content
- Clear, descriptive page title
- Optional one-line subtitle
- Text must immediately explain what the page is about
- Language should be simple, confident, and non-technical

--------------------------------------------------
LAYOUT & STRUCTURE
--------------------------------------------------

- Split-layout banner:
  • One side: image
  • One side: text
- Vertical centering of content
- Generous padding and whitespace
- Responsive behavior:
  • Desktop: side-by-side layout
  • Mobile: stacked layout (text first, image second)

The banner should feel like a calm introduction, not a marketing hero.

--------------------------------------------------
VISUAL STYLE
--------------------------------------------------

- Clean, restrained design
- Neutral background behind text
- High contrast for readability
- No heavy gradients, overlays, or decorative effects
- No clutter

--------------------------------------------------
CONSISTENCY & VARIATION
--------------------------------------------------

- Banner structure must remain identical across all internal pages
- Only the following may vary per page:
  • Image
  • Image position (left or right)
  • Title text
  • Subtitle (optional)

Do NOT create custom banner styles per page.

--------------------------------------------------
ACCESSIBILITY & PERFORMANCE
--------------------------------------------------

- Provide descriptive alt text for all images
- Ensure text meets accessibility contrast standards
- Optimize images for fast load times
- Prevent layout shift during loading

--------------------------------------------------
IMPLEMENTATION REQUIREMENTS
--------------------------------------------------

- Build the banner as a reusable component
- Component must accept props for:
  • Page title
  • Subtitle (optional)
  • Image source
  • Image position (left or right)
- Ensure production-ready responsiveness
- No placeholder content

--------------------------------------------------
QUALITY BAR
--------------------------------------------------

A visitor should immediately:
- Understand what the page is about
- Feel visual consistency across the site
- Experience a professional, enterprise-grade introduction

If an internal page feels abrupt or visually disconnected from the rest of the site, the banner system has failed.

Implement this banner system across all internal pages, excluding the homepage.
